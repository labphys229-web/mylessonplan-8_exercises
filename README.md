Цей код — це готовий шаблон вебсторінки для каталогу або платформи онлайн-курсів, яка має назву «Мої уроки». Вона призначена для зручної навігації великою кількістю навчальних матеріалів (у цьому випадку закладено аж 105 основних уроків, кожен з яких має по 10 підрозділів/частин).
Генерація карток уроків (renderLessons)
Використовуючи вкладені цикли for, скрипт автоматично створює HTML-код:

Цикл i (від 1 до 105): Генерує 105 карток основних уроків (Урок №1, Урок №2 і т.д.).

Вкладений цикл j (від 1 до 10): Для кожного уроку створює 10 міні-кнопок із посиланнями на підрозділи формату lesson-i/part-j.html (наприклад, lesson-1/part-1.html, lesson-1/part-2.html тощо). На цих кнопках виводяться номери на кшталт 1.1, 1.2, 1.3 і т.д.
